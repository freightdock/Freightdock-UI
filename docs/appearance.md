# Appearance

Freightdock's look is FinUI's. As it ships it is Washi; an administrator can give the whole instance another look with a
FinUI preset: colours, accent, corners, density, fonts and the rest.

1. Make a look at FinUI create (the link is in Settings) and copy its preset code.
2. **Settings**, **Appearance**, **FinUI preset**: paste the code, or the address or install line that holds it. What
   the code picks is listed under the field.
3. Save. The new look loads in place.

The look is the same for everybody, the sign-in page included, and drawn from the first paint with no flash. Each
browser still chooses light or dark (the switch in the menu). An empty field is FinUI as it ships.

Freightdock only ever takes the code, never CSS from the browser.
